# Vertex Copier Frontend

This project is the frontend for Vertex Copier, built with:
- React 19
- Vite
- TypeScript
- Tailwind CSS
- Redux Toolkit

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Configuration
The application configuration is managed via `public/config.json`. You can modify the `apiBaseUrl` without rebuilding the project.
